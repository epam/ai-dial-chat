# Onboarding anchors

The elements an `ONBOARDING_HINTS` entry can point at. Each hint names one
of these as its `target`; chat-api drops an entry with any other value.

> Generated by `scripts/generate-onboarding-anchors.mjs` from
> [`apps/chat/src/components/OnboardingHints/onboarding-anchors.json`](../apps/chat/src/components/OnboardingHints/onboarding-anchors.json). Edit that file and run
> `npm run docs:onboarding-anchors`; `npm run validate:docs` fails when this
> page is stale.

The chat finds each element the way assistive technology sees it — by role
and accessible name, translated into the current language — and only when
it is on screen: it has a box, sits outside an `inert` subtree and is not
`visibility: hidden`. A hint whose element is not on screen waits:

- **Tour** (`ONBOARDING_HINTS_MODE=tour`) — the tour shows the hints whose
  elements are on screen and keeps the rest for a page that renders them.
- **Beacons** (`ONBOARDING_HINTS_MODE=beacons`) — a beacon appears as soon
  as its element is rendered.

## Seeing the anchors on a page

Open any chat page with `?onboarding-anchors` in the URL (for example
`/catalog?onboarding-anchors`). Instead of the hints, the chat outlines
every anchor on screen with its `target` name and lists, in a panel at the
bottom corner, the anchors that page does not render. The page stays
usable, so you can open the sidebar or switch tabs and watch the list
change. Close the panel to drop the parameter.

## Anchors

| ------------------------ | --------------------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `navigation`             | Any page with the sidebar open          | The navigation sidebar as a whole                                                       | The on-screen `nav` landmark named like the navigation                                                                        |
| `new-chat`               | Any page                                | The New chat control: a sidebar link on desktop, a header button on mobile              | The first on-screen button or link named "New chat" anywhere on the page                                                      |
| `sidebar-toggle`         | Any page                                | The sidebar collapse button on desktop, the navigation menu button in the mobile header | A button named "Sidebar" inside the navigation landmark, else a button named "Navigation menu" inside `#main-content`         |
| `projects`               | Any page with the sidebar open          | The Projects link in the sidebar                                                        | A button or link named "Projects" inside the navigation landmark                                                              |
| `scheduled-tasks`        | Any page with the sidebar open          | The Scheduled tasks link in the sidebar                                                 | A button or link named "Scheduled tasks" inside the navigation landmark                                                       |
| `catalog`                | Any page with the sidebar open          | The Catalog link in the sidebar                                                         | A button or link named "Catalog" inside the navigation landmark                                                               |
| `file-manager`           | Any page with the sidebar open          | The File manager link in the sidebar                                                    | A button or link named "File manager" inside the navigation landmark                                                          |
| `chats`                  | Any page with the sidebar expanded      | The sidebar's chats section with the conversation list                                  | The `section` named "Chats and tasks" inside the navigation landmark                                                          |

| `user-menu`              | Any page with the sidebar open          | The user menu at the bottom of the sidebar                                              | A button inside the navigation landmark whose name contains "Signed in as"                                                    |

| `conversation-input`     | New chat, conversation and project view | The message composer's text field                                                       | The first on-screen `textarea` inside `#main-content`                                                                         |

| `conversation-starters`  | New chat                                | The starter prompts, when the selected model has any                                    | The `role="list"` named "Conversation starters" inside `#main-content`                                                        |
| `conversation-messages`  | Conversation                            | The conversation's message log                                                          | The `role="log"` named "Conversation messages" inside `#main-content`                                                         |
| `sources-panel-toggle`   | Conversation                            | The button that opens the sources panel                                                 | A button named "Open panel" inside `#main-content`; absent while the panel is open                                            |
| `projects-create`        | Projects                                | The New project button                                                                  | The first on-screen button named "New project" inside `#main-content`                                                         |
| `projects-search`        | Projects                                | The projects search field                                                               | The `search` element around the input named "Search projects" inside `#main-content`                                          |
| `project-chats`          | Project view                            | The project's chats section, with its composer                                          | The `section` named "Project chats" inside `#main-content`, once the project has loaded                                       |

| `catalog-tabs`           | Catalog                                 | The catalog's entity tabs                                                               | The first `role="tablist"` inside the catalog `section`                                                                       |
| `catalog-view-mode`      | Catalog                                 | The catalog's grid/list switch                                                          | The `role="radiogroup"` named like the view switch inside the catalog `section`                                               |

A renamed control or a changed role silently stops its anchor from
resolving. `apps/chat/src/components/OnboardingHints/tests/onboarding-targets.spec.tsx`
covers every resolver against fixture markup.
