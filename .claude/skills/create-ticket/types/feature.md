# Feature

Type labels: `enhancement` and `to-be-documented` (always). See `../labels.md`.

## Fields to gather (Step 3)

Ask each as a separate question via **AskUserQuestion** (open-ended). Skip any field already covered by the approved Step 2 draft.

1. **Description**: Ask:
   > "Describe the feature. What should it do and why is it needed?"
2. **Related issues** (optional): Ask:
   > "Are there any related issues? (paste issue numbers/URLs or skip)"

## Body format (Step 8)

```markdown
### Description

<description>

### Related issues

<issues or "_No response_">

### Details

<details-section>

### Confidential information

- [x] I confirm that do not share any confidential information
```
