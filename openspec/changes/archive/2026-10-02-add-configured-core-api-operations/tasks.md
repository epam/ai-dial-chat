## Client application integration (outside this change's implementation scope)

After the shared BFF release, client applications can supply the required operation mapping through the BFF's CUSTOM_CORE_API_CONFIG environment setting and connect their domain adapters to the generic response envelope. Each client owns its runtime domain validation, presentation, loading/error handling and corresponding integration tests.

Before enabling an integration, confirm the deployed Core version, route's static/upstream form, roles/data scope, path collisions, trusted upstream and export/sync state through the deployment's automated acceptance process. The BFF's mocked tests do not prove these deployment facts. Client-specific persistence and APIs requiring query/body/writes remain separate contracts.
