# Tasks

Slicing strategy: **contract-first, then one vertical path.** Slice 1 fixes the wire contract on the backend (the optional `generationId` on the attach `snapshot`) with its tests, docs and OpenAPI output. Slice 2 consumes it in `libs/chat-hooks` so that, with slice 1, a refreshed non-background generation can be stopped end to end. Each slice carries its own tests and docs. Read `apps/chat-api/AGENTS.md` before slice 1 and `.claude/rules/libs.md` before slice 2.
