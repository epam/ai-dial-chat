# Tasks

Slicing strategy: **risk-first, then vertical.**
- Group 1 proves the DIAL Core/adapter behavior every later group depends on. Its stop-gates must pass, or the user must decide, before group 2 starts.
- Groups 2–4 lay the contract: the flag, the message field, and the Core client.
- Groups 5–10 each land one path through the stack with its own tests and docs.
- Group 11 is integration-only.

Conventions for every group:
- Backend work follows `apps/chat-api/AGENTS.md`.
- Relative TypeScript imports are extensionless.
- Specs sit next to the code they test, in each folder's existing `tests/` subfolder.
- Run the named spec files with `npm run test:file -- <path>`, then `npm run verify:changed` once the group is done.
