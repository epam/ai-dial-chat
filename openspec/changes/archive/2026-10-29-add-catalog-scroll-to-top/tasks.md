Slicing strategy: **vertical, grid view first.** Slice 1 ships the button end to end in grid view (hook, button, Catalog wiring, search focus). Slice 2 widens it to list view through the `ListView` handle. Slice 3 adds the host label, README and the final gate. Each slice is independently verifiable.

Conventions for every task: relative imports stay extensionless; module-level helpers are `const` arrow functions; lib strings are props with English defaults (no `useTranslation` in `libs/catalog`); Tabler icons take `stroke={DIAL_KIT_ICON_STROKE}`; tests query by role/label, never `data-testid`.
