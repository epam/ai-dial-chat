# Tasks

Slicing strategy: **risk-first, then vertical.** Group 1 lands scaffolding and fixes the riskiest shared piece (URL cleanup that cannot wipe other params, wired into `ConversationRoute`). Groups 2-4 each deliver one parameter end to end (hook source + route wiring + tests). Group 5 adds the combination and cross-cutting guards (StrictMode, isolated, overlay). Group 6 reconciles specs, docs and closes verification. Each group depends on the previous one. Read `AGENTS.md`, `.claude/rules/apps.md`, `.claude/rules/all-ts.md` and `.claude/rules/docs.md` before starting. Relative TypeScript imports are extensionless; `apps/chat` keeps `moduleResolution: bundler`. No `libs/*` file was planned to change; the one exception, `libs/conversation-input` (see 5.3), was raised as a scope change and approved during implementation.
