## Decisions

Multer and the write services read the server's validated count. Edits count retained and added files. An optional form prop preserves existing hosts, and the chat application reuses its too-many-files translation.

An independent archive budget gives operators room for the manifest, ZIP overhead, conversations and artifacts. Apply it to declared and streamed lengths, retaining the manifest reservation at startup and the existing read concurrency limit.

The file manager checks count and known byte sizes before confirming a selection. All response streams from one selection share a byte budget. This covers absent or outdated metadata and leaves the form's validation of staged files in place.

Multipart text fields retain Multer's default allowance for small projects. For large projects the allowance grows to fit a compact JSON array of the maximum number of valid 255-byte names, including quotes, commas and brackets.
