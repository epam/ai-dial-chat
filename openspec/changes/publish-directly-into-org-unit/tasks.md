# Tasks

Slicing strategy: **contract-first, then risk-first.** The rights rule and the copy endpoint's new fields are the contract both sides build on, so they land first (groups 1-2); the flow and panel (group 3) and the host wiring (group 4) follow on a contract that no longer moves. Run `npm run verify:changed` once after each completed group and close the change with exactly one `npm run verify:full` (with `NX_LOAD_DOT_ENV_FILES=false`) and, because bundling can be affected, one `npm run build:quiet`. Read `apps/chat-api/AGENTS.md` before groups 1-2 and `.claude/rules/libs.md` before groups 1 and 3. The branch stands on the work that saves an application with its dependencies into an org unit (change `save-application-with-dependencies-to-org-unit`, already archived into the main specs, in review as a pull request); its tasks assume that code is in the branch.
