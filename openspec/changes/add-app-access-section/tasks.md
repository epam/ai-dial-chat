# Tasks

Slicing strategy: contract-first. The API contract and the pure mapping land first (nothing visible), then the library UI against fixtures, then the thin host wiring. Slices 1-3 do not depend on the open design questions; slice 4 carries the defaults from `proposal.md` and `design.md` (D9) and stays adjustable through labels and visibility only. The feature is not gated by `ENABLED_FEATURES` / `ENABLED_FEATURES_ROLES`: visibility is per app definition, authorization is decided by DIAL Core. No new telemetry or metrics are emitted. Any Core refusal is surfaced to the author, not logged beyond the existing `Logger` warn line in the save-error mapper.
